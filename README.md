# Scrollwise

ScrollWise is a C++ console-based application that helps users log, track, and reflect on their digital scrolling habits. 

Features

Log scroll sessions (app, date, duration, content type)
Set and track daily scrolling goals
View total time spent
Get reflective insights

How It Works
Built around a vector of ScrollSession structs. Each session stores the app name, date, duration, content type, and daily goal. Totals and insights are computed by iterating through the vector using loops.
